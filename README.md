Readability of Fonts Project
This repository contains an experiment designed to investigate how different font sizes impact the readability and reading speed of text. The project includes data collection, analysis, and visualization, using eye-tracking data to assess user interaction with various font styles and sizes. The final report was generated using Quarto, integrating both the data analysis and visualizations into a comprehensive document.

Features:
Data Collection: Gathered eye-tracking data, including metrics such as saccades and fixations, to analyze reading patterns.
Font Variations: Tested different font sizes to observe their effects on reading speed and comprehension.
Data Visualization: Utilized R for visualizing the data and drawing conclusions about the readability of fonts based on the collected eye-tracking metrics.
Final Report with Quarto: Combined data analysis and visualizations into a cohesive, dynamic report using Quarto.
Technologies Used:
Python (for data collection and analysis)
R (for data visualization)
Quarto (for generating the final report)
Eye Tracking Tools (used for experiment setup and data collection)
Installation:
Clone the repository to your local machine.
Open the project files in your preferred environment to analyze the data and replicate the experiment.
